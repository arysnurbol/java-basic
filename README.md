## Қалай жұмыс істейді

Әр тапсырма — `src/chNN/` ішіндегі жеке пакет. Онда екі түрлі файл бар:

* **қаңқа кластар** (`Book.java`, `Box.java`, …) — ішінде `// TODO` жазулары.
  Сен тек осы файлдарды өзгертесің.
* **`TaskNNCheck.java`** — тексеріс. Оны өзгертудің қажеті жоқ, бірақ **оқы**:
  әр тапсырмадан не күтілетіні дәл сонда жазылған.

## Жүгірту

```powershell
# 2-глава
.\check.ps1            # барлық тапсырма
.\check.ps1 3          # тек 3-тапсырма
.\check.ps1 3 5 7      # бірнешеуі

# 3-глава
.\check.ps1 ch3        # барлық тапсырма
.\check.ps1 ch3 12     # тек 12-тапсырма
```

Git Bash қолдансаң: `./check.sh 3` немесе `./check.sh ch3 12`

Шығатын нәтиже:

```
=== Тапсырма 03 — Конструктор түрлері (Rectangle) ===
  [ OK ] no-arg konstruktor -> width == 1
  [FAIL] Rectangle(3,5) -> area == 15  (күтілген: 15.0 ±1.0E-9, келген: 0.0)
```

`[FAIL]` жолында әрқашан **не күтілді** және **не келді** деп жазылады.

## IntelliJ IDEA-мен

`src` папкасын Sources Root ретінде белгіле
(оң жақ түйме → *Mark Directory as* → *Sources Root*), содан кейін
`Ch02Runner` / `Ch03Runner` немесе кез келген `TaskNNCheck` класын тікелей Run жаса.

## Жұмыс тәртібі (ұсыныс)

1. Сәйкес TASKS файлынан тапсырманы оқы.
2. Кітаптағы сәйкес бетке көз жүгірт (әр тапсырмада бет нөмірі көрсетілген).
3. Қаңқадағы `// TODO` орындарын толтыр.
4. `.\check.ps1 <нөмір>` — бәрі `[ OK ]` болғанша қайтала.
5. Өтті — келесіге көш.

**2-глава** тақырып бойынша реттелген: 1–7 негіздер, 8–11 мұрагерлік пен
полиморфизм, 12–14 абстракция мен инкапсуляция, 15–16 жобалау тәсілдері.

**3-глава:** 1–4 обобщения, 5–7 лямбда мен функционалдық интерфейстер,
8–10 коллекциялар, 11–13 Stream API, 14–16 көпағындылық,
17–18 рефлексия мен аннотациялар, 19 файлдар, 20 ерекше жағдайлар.
