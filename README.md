## Қалай жұмыс істейді

Әр тапсырма — `src/ch02/` ішіндегі жеке пакет. Онда екі түрлі файл бар:

* **қаңқа кластар** (`Book.java`, `Student.java`, …) — ішінде `// TODO` жазулары.
  Сен тек осы файлдарды өзгертесің.
* **`TaskNNCheck.java`** — тексеріс. Оны өзгертудің қажеті жоқ, бірақ **оқы**:
  әр тапсырмадан не күтілетіні дәл сонда жазылған.

## Жүгірту

```powershell
# барлық тапсырманы тексеру
.\check.ps1

# тек бір тапсырма
.\check.ps1 3

# бірнешеуі
.\check.ps1 3 5 7
```

Git Bash қолдансаң: `./check.sh 3`

Шығатын нәтиже:

```
=== Тапсырма 03 — Конструктор түрлері (Rectangle) ===
  [ OK ] no-arg konstruktor -> width == 1
  [FAIL] Rectangle(3,5) -> area == 15  (күтілген: 15.0 ±1.0E-9, келген: 0.0)
```

`[FAIL]` жолында әрқашан **не күтілді** және **не келді** деп жазылады.

## IntelliJ IDEA-мен

`src` папкасын Sources Root ретінде белгіле
(оң жақ түйме → *Mark Directory as* → *Sources Root*), содан кейін
`Ch02Runner` немесе кез келген `TaskNNCheck` класын тікелей Run жаса.

## Жұмыс тәртібі (ұсыныс)

1. TASKS.md-тен тапсырманы оқы.
2. Кітаптағы сәйкес бетке көз жүгірт (әр тапсырмада бет нөмірі көрсетілген).
3. Қаңқадағы `// TODO` орындарын толтыр.
4. `.\check.ps1 <нөмір>` — бәрі `[ OK ]` болғанша қайтала.
5. Өтті — келесіге көш.

Тапсырмалар тақырып бойынша реттелген: 1–7 негіздер, 8–11 мұрагерлік пен
полиморфизм, 12–14 абстракция мен инкапсуляция, 15–16 жобалау тәсілдері.
